A high-performance, ROS 2 autonomous racing stack designed for the **Edinburgh University Formula Student (EUFS)** simulator. This repository contains a complete pipeline—from state estimation and mapping to path planning and high-speed vehicle control—built to handle high-speed vehicle dynamics, severe sensor noise, and tight hairpin drifting.

## 🏁 About EUFS
[Formula Student](https://www.imeche.org/events/formula-student) is Europe's most established educational engineering competition. The Autonomous Design (FS-AI) category challenges university teams to develop self-driving software for a fully autonomous race car. 

The [EUFS Simulator](https://gitlab.com/eufs/eufs_sim) is a highly realistic Gazebo-based physics environment used by teams worldwide to test their algorithms on tracks marked by colored cones (Blue = Left, Yellow = Right, Orange = Track Limits/Start Line).

## 📦 System Architecture

This repository is split into four core packages that form the autonomous pipeline.

### 1. State Estimator (`my_stateestimator_pkg`)
* **Role:** High-frequency local odometry and noise filtering.
* **Overview:** A lightweight Extended Kalman Filter (EKF) that fuses raw wheel speeds and IMU data to provide a smooth, continuous estimate of the car's position and velocity. 
* **Key Features:** Mutually Exclusive Gating, anti-color-bias sequential shuffling, and zero-latency TF tree synchronization.

### 2. Global SLAM (`my_slam_pkg`)
* **Role:** Map building and track loop closure.
* **Overview:** A EKFSLAM, FastSLAM, GraphSLAM architecture that maps the track boundary cones while eliminating accumulated odometry drift.
* **Key Features:** Contains EKF, particle and Graph based slam also includes Cmakelist.txt and package.xml"

### 3. Path Planner (`fsd_planner`)
* **Role:** Dynamic trajectory generation.
* **Overview:** Takes the map of blue and yellow cones generated by the SLAM node and computes the optimal racing line. 
* **Key Features:** Path planning node also contains setup.py and package.xml

### 4. Hybrid Controller (`my_controller_pkg`)
* **Role:** High-speed tracking and actuation.
* **Overview:** Translates the planned trajectory into precise steering, throttle, and braking commands.
* **Key Features:** It includes PurePursuit controller code and a curvature weightage based controller code which fuses Pure Pursuit and stanley also includes Cmakelist.txt and package.xml

## ⚙️ Prerequisites

Before building this stack, ensure you have the following installed:
* **OS:** Ubuntu 22.04
* **Middleware:** [ROS 2 Humble](https://docs.ros.org/en/humble/Installation.html)
* **Simulator:** [EUFS Simulator](https://gitlab.com/eufs/eufs_sim)
* **Math Libraries:** `Eigen3`, `GTSAM`

To install GTSAM system-wide:
```bash
sudo apt-get install software-properties-common
sudo add-apt-repository ppa:borglab/gtsam-release-4.1
sudo apt-get update
sudo apt-get install libgtsam-dev libgtsam-unstable-dev
